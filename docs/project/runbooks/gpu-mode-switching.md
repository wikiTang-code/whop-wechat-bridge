# Runbook — GPU 显存模式切换与打游戏共存指南 (Game vs Work Mode)

> **目标**：在宿主机 AMD Radeon RX 7900 XT（20GB 显存）环境下，提供秒级切入「游戏模式」（0GB 显存占用）与「工作模式」（14B 满血装载），确保 3A 大型游戏与微信量化网桥两不误。

---

## 1. 核心运行原则

1. **游戏模式（100% 显存归还）**：
   - 触发卸载指令后，显卡显存中的模型（14B）在 1 秒内完全卸载排空，显存占用直接降为 **0.00 GB**；
   - 释放全部 20GB VRAM 给大型 3A 游戏（如《黑神话：悟空》、《赛博朋克 2077》等）。
2. **网桥平滑降级（绝不崩端、不漏单）**：
   - 游戏模式下，若收到大V盘中发言，网桥自动降级为**规则正则抽取引擎（Fast Lane Fallback）**；
   - 核心交易跟单与企微卡片推送依然完全正常工作。
3. **工作模式（一键满血恢复）**：
   - 游戏结束后一键恢复，自动将 14B 深度模型重新加载至 GPU，恢复深车道 AI 语义解析。

---

## 2. 切换操作方式

### 方式 A：Windows 桌面双击（最便捷 · 零控制台）

项目根目录 scripts/ 提供了两个批处理快捷脚本，可创建桌面快捷方式随时双击：
- **打游戏前**：双击运行 scripts/game_mode.bat
  - 自动执行显存排空，提示「显存已完全释放（当前占用 0.00 GB / 20 GB）」。
- **打完游戏**：双击运行 scripts/work_mode.bat
  - 自动将 14B 深度推理模型装载至 GPU 显存。

### 方式 B：npm / 控制台快捷指令

在项目根目录下，支持以下封装命令：

`powershell
# 1. 切换至游戏模式 (释放全部显存)
npm run game:mode
# 或别名: npm run gpu:release

# 2. 切换至工作模式 (满血装载 14B)
npm run work:mode
# 或别名: npm run gpu:restore

# 3. 随时查看当前显存占用情况
npm run gpu:status
`

---

## 3. 空闲自动退避机制 (TTL)

若未手动切换，系统亦具备自动保护机制：
- LM Studio 后台无头服务默认配置了 **空闲 TTL（3600s / 1小时）**；
- 当连续无新消息或无推理调用达到空闲时长后，模型会自动从显存中卸载排空。
