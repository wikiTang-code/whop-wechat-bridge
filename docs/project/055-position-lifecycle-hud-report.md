## 1. 核心特性与界面实现细节 (去绝对化)

### ① 大V口述资金纪律感知看板 (`.capital-banner`)
- **来源定义**：`zhao_quote`（口述发言引用）+ `heuristic`（启发式评估）；
- **界面指标呈现**：
  - 正股底仓估算（建议 80%~90%，高贝塔正股与战车为主）；
  - 期权仓位估算（建议 <=10%，仅作为脉冲或融资小仓）；
  - 现金缓冲估算（常规保持 2%~10%）；
  - **合规告警灯**：若期权占比 >12% 亮黄色超配预警，明确标明 `[来源: zhao_quote 口述引用 · 非券商实盘]`。

### ② 重点标的推演持仓控制台 (`.lifecycle-section`)
- **收窄展示焦点短列表**：按最近操作时间倒序排列，优先展示最近最活跃的前 8 个焦点标的，消除 44 个标的过度膨胀的噪声；
- **状态流转可视化 (标明 heuristic)**：
  - `1/6 首单低吸 [heuristic]`：首单试探与二次平摊推演均价；
  - `🛡️ 半仓止盈 · 保本损锁定 [heuristic]`：脉冲急拉半仓锁利，剩余半仓止损线推升至开仓均价；
  - `⚡ 低吸加回做T [heuristic]`：高抛后提示 `~$Price (启发式 -4%)` 回调目标接回买点；
- **风控点位清晰标注**：
  - `推演持仓均价: $XXX`
  - `推演保本止损线: $XXX`
  - `启发式硬止损 (-5%): $XXX`
  - 卡片顶部醒目标注 `[heuristic]` 标签，杜绝驾驶员将推演数字误当成券商成交真相。

### ③ 四维共振卡片实时状态贴合 (`.ticker-pos-pill`)
- 仅作为只读上下文信息注入徽章（如：`💼 推演跟踪: 半仓止盈保本 · 推演保本损 $215.4`）；
- **坚决不改动四维共振打分**，四维微观结构（GEX、大V多模态、成交单偏差、盘口大单）评分逻辑保持完全独立。
