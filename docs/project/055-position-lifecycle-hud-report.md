## 1. 核心特性与界面实现细节

### ① 大V宏观资金分配看板 (`.capital-banner`)
- **铁律工程化**：依据赵哥多次提及的实盘资金纪律，实现 `CapitalAllocationModel` 自动化评估。
- **界面指标呈现**：
  - **正股底仓占比**（建议 80%~90%，高贝塔正股与战车压舱）；
  - **期权占比**（严格限制 <=10%，仅作为脉冲加速或末端融资跟进）；
  - **现金缓冲比例**（常规保持 2%~10%）；
  - **合规态势警示**：若期权占比 >15% 自动亮黄灯 (`OPTION_OVERWEIGHT`)，若 >30% 触发红灯告警 (`CRITICAL_LEVERAGE`)。

### ② 实战战术持仓动态做T控制台 (`.lifecycle-section`)
- **状态流转可视化**：
  - `INITIAL_1_6TH`：1/6 首单低吸试探；
  - `HALF_PROFIT_TAKEN_BREAKEVEN`：🛡️ 脉冲急拉半仓止盈 · 剩余仓位强制锁定保本损；
  - `T_DIP_BOUGHT`：⚡ 低吸加回做T，底仓成本直接摊薄；
  - `CLOSED`：全生命周期闭环。
- **动态风控点位一目了然**：
  - **战术均价**（动态加权成本）；
  - **保本止损线**（半仓止盈后自动锁定在开仓均价，彻底告别浮盈变浮亏）；
  - **初始硬止损**（开仓即钉死 -5% 硬止损）；
  - **做T差价参谋**：若标的有最近高抛卖出，自动锚定高抛价格并提示 `~$Price (-4%)` 目标接回买点。

### ③ 四维共振卡片实时状态贴合 (`.ticker-pos-pill`)
- 在雷达卡片网格中，如果检测到该标的正处于大V活跃跟踪持仓中，自动在卡片顶部注入徽章（例如：`💼 活跃持仓: 半仓止盈保本 · 保本损 $215.4`），让驾驶员在观察盘口与做市商共振态势的同时，瞬间了解决策上下文。
