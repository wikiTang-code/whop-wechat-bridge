## 2. 战法知识图谱体系演进（超越传统人工 7 大分类）

早期人工归纳的 7 大分类（如“盘前做T”、“尾盘抄底”等）存在**时钟、空间、形态与心态混杂、分类颗粒度不均**等局限。
基于 1,850 张卡片的无监督余弦流形拓扑与微观机理，建议将大V实盘操盘体系重构为 **4 层正交本体认知框架**：

### 维度说明
1. **① 时间潮汐时钟层 (Temporal Tidal & Session Regimes)**：以美东时钟为第一驱动力，捕捉日内流动性在不同时段（开盘冲击、早盘冲高、尾盘强平、夜盘/盘前冷门时段）的周期性规律；
2. **② 空间结构引力层 (Spatial Mechanics & Gaps)**：以价格图表上的物理空间（跳空缺口、做市商持仓密集区、历史成交密集位）为磁场引力，判定反弹目标位与阻力回撤区；
3. **③ 微观流动性失衡层 (Microstructure & Orderflow Imbalances)**：以盘口大单流（Block/Sweep）、散户强平止损单密集踩踏为对手盘，在对手盘卖压出清的一瞬间完成右侧点火；
4. **④ 非对称风控纪律层 (Risk Discipline & Asymmetry)**：以极窄硬止损锁定下行最大亏损空间，以分批建仓与仓位二分法实现知行合一，切断左侧抗单的毁灭性风险。

## 3. 后续立项规划：`REQ-049-C2`（自适应事件窗口短周期微观复验）

针对 049-C 日 K 回测中暴露的“时钟战法与日 K 粒度失配”问题，正式立项规划后续专项：**`REQ-049-C2`**。

### 核心方法学蓝图（不搞全历史扫参，自适应短窗口）
1. **事件时点绝对锁定**：以消息发送时间 $t_0$（美东时间，时分秒）为锚点；
2. **首根可成交 Bar**：盘中即时指令，取 $t_0$ 之后第一根有效交易 Bar 的 Open 价作为基准入场成本；
3. **短周期局部窗口抓取**：
   - 依赖本地已跑通的长桥 OpenAPI / 富途 OpenD 行情引擎；
   - 仅拉取 $[t_0 - 30\text{m}, t_0 + \text{Horizon}]$ 的局部高频 K 线（5m / 15m / 30m），严防券商 API 额度超限；
4. **匹配机理的可计算代理指标**：
   - **减仓战法**：检验窗口内是否出现相对开盘/成本的冲高回落，计算最大有利偏移（MFE）；
   - **缺口战法**：检验数日内是否触达缺口位，以及触达前的最大不利偏移（MAE）；
   - **硬止损战法**：检验入场后硬止损是否被击穿；若击穿，检验后续是否出现更大跌幅（验证“止损是否真起到了保护作用”）；
5. **坚持四态弱检验**：样本量门禁依然有效，分时检验仍输出 `supportive / inconclusive / contradictory / insufficient`。
