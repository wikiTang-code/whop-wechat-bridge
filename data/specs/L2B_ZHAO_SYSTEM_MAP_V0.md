目的：把一年口播收成可扫、可补洞的一张图。  
不是交易手册，不是 registry，不是训练数据。

图例：`E` 库内已有原句/图；`R` 用户补的结构、待 SQL 证实；`U` 见过但未定位（G1–G3）。

## 0. 总结构（四层，自上而下）

```
L0 阶段钟     现在处在哪一段：回流 / 冲击 / 反复 / 财报轮动 / 周五结算 / 节前被动减 / 讲话窗
L1 指数尺     当日 SPX/SPY 的活动范围、量能、结构（二次握手、波动值、60点）
L2 板块仓     多袖子分仓 + 财报先后轮动 + 龙头迭代（弱则成本出）
L3 执行闸     转弯/回踩时段、急跌一起吸、缺口做两次、开仓一半、两段式、禁止把课当自动单
```

先定 L0，再用 L1 的尺，再在 L2 里选袖子，L3 只决定「何时碰、碰多大」。周原子（PCR/墙/四体制）是对照层，不进主线。

## L1 指数尺

三把尺同时存在，不要并成一个 kid。

1. **阶段振幅（波动值）**  
   回流端用户回忆 SPX 日内约 60 点；起算是「当日最高往下」还是「开盘」**未证实**。  
   `U` G1「知道了波动值卖在最高，底区急跌接」。`wave_value` 旧检索 0 次 → 必须加 `60点|每天波动|从最高|从开盘`。

2. **结构尺**  
   二次握手 / 第一轮低点不破 / 平行探底 / 7339 双底。`E` G4、g_img_003、握手 5 句。

3. **量能尺**  
   冲高量不够才砸、节后成交额 1.5 倍。`E` t_prop_010；`R` 量能不够。

尾盘 V、3:50、期权盈亏：`U` G2，属期权钟，挂在 L1 旁路，不是主趋势尺。

## L2 板块仓

- 同时持有多个板块袖子：大盘、明星、加密、存储、光、软件…（`R`，检索：分仓|板块|龙头|存储|光模块|软件）
- 每袖子代表性龙头即可，不堆同板块一只
- 财报日历决定哪只袖子先弱先强（`R` + earnings hits）
- 一轮下来弹得慢、不强势 → 成本出，下次换更强（`R`，检索：成本出|换标|不强势|回弹慢）
- 高低切：强的一段兑现，弱的回流再接（`R`）
