# 赵哥体系系统图 v0.1

相对 v0 的修正：周五/节前不是阶段钟，是**日历律**。  
阶段钟 = 大事件周期。指数振幅随阶段变，有的阶段没有稳定点差。  
另加：打油诗总诀、股性层。

图例：`E` 已有原句/图；`R` 结构待扫；`P` 打油诗（待对库）；`U` 未定位。

## 分层（改准后）

```
L0 事件周期     大选/中选、回流、关门、贸易战、美伊、财报季、节日串、重大讲话、系统性跌价
Lcal 日历律     每个事件阶段里都可能出现：周五结算/多空双杀、节前两日、节后回流、尾盘两段
L1 指数尺       该周期下 SPX 当日有没有稳定振幅（回流或有约60点；有的周期没规律）
L2 板块仓       多袖子 + 财报先后轮动 + 高低切 + 弱标成本出
L2p 股性        同一闸门在 TSLA / 腰斩型 / 加密上用法不同
L3 执行闸       转弯、回踩、缺口、握手、半仓两段… 全部 do_not_use_as_order
Lpoem 总诀      打油诗（横切 L0/Lcal/L3）
```

周原子仍是对照，不进主线。

## Lcal 日历律（常规，不是阶段）

- 周五：多空双杀 / 结算 put / 靴子落地普涨（E 送审 5 句）
- 节前两日布局、节前勿抢、节后资金回流吃肉（P + E 被动减）
- 事件日：尾二收盘低吸，莫急闯；靴子落地持股等红（P）
- 盘前半小时 / 开盘回踩（E）
- 收盘开仓、大回调两段式（E 008）

## L1 指数尺（随 L0 变）

- 有的周期有稳定点差：回流端用户忆 SPX 约 60 点，起算最高还是开盘待原句（U/R，G1 波动值同族）
- 有的周期「指数没有那么有规律」——这时放下点差尺，改用结构尺（二次握手/平行不破）或直接看个股股性
- 量能：冲高量不够才砸（R）
- 禁止把 60 点写进所有周期

## Lpoem 打油诗总诀 (已全量证实: gold_text)

原帖出处：`post_1CWoRBJvkuBQgdN2Cq7Mci` (2026-01-04 · 发布区)，含口诀与赵哥亲笔白话文：

```
口诀
普跌同沉不用慌，收盘寻底看稳当；   # 系统性普跌：收盘看底稳不稳
普涨我跌要提防，减持利空细查详。   # 指数红个股绿：查该股利空/减持
事件来临莫急闯，尾二收盘低吸仓，   # 事件前不抢，最后两段收盘低吸
靴子落地迎反弹，持股静待红盘扬。   # 落地后拿反弹
节日前夕别乱抢，节前两日布局忙，   # 日历：节前-2
节后资金回流至，顺势吃肉把利装。   # 节后回流
币市波动要盯紧，首阴一跌需警醒，   # 加密股性
首阳一涨别贪猛，信号初现辨分明。   # 第一根信号
```

工程用诗中整句/半句扫库，命中则 P 变为 E。
