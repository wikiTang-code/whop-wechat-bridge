## 一、PCR (Put/Call Ratio) 情绪指标配方

### 1. 指标定义
$$\text{PCR} = \frac{\text{Put 总成交量}}{\text{Call 总成交量}} \quad \text{或} \quad \text{PCR}_{\text{OI}} = \frac{\text{Put 未平仓量 (OI)}}{\text{Call 未平仓量 (OI)}}$$

### 2. 真实观察分档（严格按 1,447 条样本实测切片，空档不补）

| PCR 实测区间 | 语义标签 | 市场状态 | 样本佐证 |
| :--- | :--- | :--- | :--- |
| $\text{PCR} \le 0.88$ | **偏进攻 (Bullish / Risk-On)** | 市场看涨期权活跃，多头情绪主导 | 实测研报样本 |
| $0.90 \le \text{PCR} \le 1.02$ | **均衡 (Neutral / Balanced)** | 多空力量势均力敌 | `PCR 0.98（均衡）` |
| $\text{PCR} \ge 1.06$ | **偏防守 (Bearish / Risk-Off)** | 市场避险对冲买 Put 显著上升 | 实测研报样本 |
| *其他未见区间* | **未定义 (Undefined / Raw Value Only)** | 仅保留原始读数，禁止脑补规则 | 保持观察 |

## 二、期权墙 (Option Wall) 支撑与阻力位算法

### 1. 扫描窗口
- 以标的当前价格 $P_{\text{current}}$ 为基准，限定扫描区间为 **$[0.85 \times P_{\text{current}},\; 1.15 \times P_{\text{current}}]$**（现价 $\pm 15\%$）；
- 标的交割月：取当前最近活跃主合约期权链。

### 2. 点位计算
- **上行 Call 墙 (Call Wall / 强阻力位)**：
  $$\text{Strike}_{\text{CallWall}} = \arg\max_{K \in [P_{\text{current}}, 1.15 P]} \text{OI}_{\text{Call}}(K)$$
  * 含义：上方最大 Call 未平仓行权价（庄家卖 Call 压制区）。
- **下行 Put 墙 (Put Wall / 强支撑位)**：
  $$\text{Strike}_{\text{PutWall}} = \arg\max_{K \in [0.85 P, P_{\text{current}}]} \text{OI}_{\text{Put}}(K)$$
  * 含义：下方最大 Put 未平仓行权价（庄家买 Put 护盘区）。

## 三、行情体制分类矩阵 (Market Regime Matrix)

### 1. 基础输入
1. **SPY 20日收益率 (SPY20d)**：$\text{SPY}_{20d} = \frac{\text{SPY}_{\text{now}} - \text{SPY}_{20\text{d ago}}}{\text{SPY}_{20\text{d ago}}} \times 100\%$
2. **VIX 波动率读数**：即时点位（如 $18.0$）

### 2. 体制分类与模型适性（基于真实研报结构，无臆造死区）

| 体制组合 | 官方体制名称 | 模型适性 (Model Fit) | 原文决策指引 |
| :--- | :--- | :--- | :--- |
| $\text{SPY}_{20d} \ge 0\%$ | **偏多市 × [低/中波动]** | 模型进攻区 / 适性良好 | 顺势关注支撑位表现 |
| $\text{SPY}_{20d} < 0\%$ | **震荡市 × 中波动** | 模型中性区 (Neutral Fit) | 原文基线：按关键位与主模型信号综合判断 |
| 波动率异动 | **偏空市 / 高波动** | 模型观察区 (Watch) | 方向观望，以关键位可信度与期权墙为辅助 |

## 四、分档限价建议 (Price Tiering) 规范

### 1. 字段语义
- **命中价格 (Hit Price)**：信号生成瞬间的标的即时价（如 `706.70`）；
- **建议价格 (Suggested Price)**：经过微观盘口微调后的挂单限价（如 `706.66`）。

### 2. 限价等级定义
- **中性 (Neutral)**：当前教材 840/840 条唯一出现且锁定的等级。挂在即时买一/卖一与点位缓冲区，绝不以市价追单；
- **其他等级**：保守 / 激进仅作为保留字段名，在未有真实公式前禁止自行发明计算逻辑。

## 五、GEX 与 Skew 代理（单列观察项）

- **GEX (Gamma Exposure) 代理**：基于期权链 OI 估算整体庄家 Gamma 正负状态，单列观察；
- **Skew 代理**：基于 OTM Put 与 OTM Call 的隐含波动率差值，单列观察，不设人为硬阈值。

## 六、周哥策略纪律萃取（4条已验证铁律）

1. **时段纪律**：盘中即时计算易引入未收盘假突破，**核心扫描与分析窗口为夜盘与盘前**；
2. **资金管理**：回测默认单笔名义 1 万美金，最大并发重叠持仓 $\le 3$ 笔；
3. **出场纪律**：到期无条件平仓，禁止主观抗单；
4. **定位铁律**：**最合适定位是做风控参考与盘面过滤器，严禁作为闭眼全自动买卖指令**。
