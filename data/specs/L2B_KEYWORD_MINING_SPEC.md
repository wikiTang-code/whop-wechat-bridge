# L2b 关键词挖掘 v1

复合词整词 tf=0 不代表概念不存在。头词独立统计，补语可选。

## 拆法（头词必须单独进表）

| 整词（严） | 头词（必统计） | 补语（可选加分） | 注意 |
|---|---|---|---|
| 二次握手 | 握手 | 二次、探底、不破 | 握手单独会混「握手言和」，抽课时看邻字 |
| 急跌买回 | 急跌 | 买回、急涨、异动 | 急跌已是高频头词 |
| 60点 | 60 且邻域有 波动/区间/点/上下 | 点 | 「波动是60」算命中尺 |
| 靴子落地 | 靴子 | 落地、结算 | 「落地」太宽，不单独当策略词 |
| 反弹一半 | 反弹 | 一半、(a+b)/2 | 「一半」单独太宽（出一半是仓位） |
| 被动减持 | 被动减 | 减持、留现金 | |
| 高低切 | 高低切 | 切到、移入 | 整词保留，已 12 次 |

score 仍打在**词条**上，不打整句。句中有「了」不影响「急跌」计数。

## 字段

- tf: 含该词的消息数
- act: 同条含动作词
- n_months / looks_like_l2a_ratio / score / bucket 同前

口语虚词（了啊这种可以就是）只从**词表**剔除，不删句子。
