## 三、真实状态机转移图 (FSM)

```mermaid
stateDiagram-v2
    [*] --> WATCH: 初始监听 / 盘前扫描
    
    WATCH --> LONG_ACTIVE: 命中 [Ⅲ / 底] (124次) 或 [底结构形成 / 抄底] (81次)
    WATCH --> LONG_SETUP: 仅命中 [底结构形成] (单原子)
    LONG_SETUP --> LONG_ACTIVE: 随后命中 [Ⅲ] / [底] / [抄底]
    
    LONG_ACTIVE --> RISK_WARNING: 命中 [顶结构形成] (144次) 或 [减仓] (100次)
    RISK_WARNING --> LONG_ACTIVE: 重新命中 [Ⅲ / 底] / [抄底]
    
    RISK_WARNING --> FLAT: 命中 [卖出] (123次) / [卖出/顶结构] (164次) / [清仓] (67次)
    LONG_ACTIVE --> FLAT: 命中 [卖出] / [清仓] / [到期]
    
    FLAT --> WATCH: 重置冷却
```

### 核心流转规则：
1. **主多头入口**：以 `Ⅲ / 底`（124次）和 `底结构形成 / 抄底`（81次）为两大直接进入 `LONG_ACTIVE` 的主路径；
2. **防守过渡态**：以 `顶结构形成`（144次）与 `减仓`（100次）进入 `RISK_WARNING`；
3. **离场终态**：以 `卖出 / 顶结构形成`（164次）、`卖出`（123次）、`清仓`（67次）直接退出到 `FLAT`；
4. **隔离说明**：本状态机为群友纯技术原子状态机，与大V L2b 战法融合在后续单独的 Fusion 规范中定义，绝不在此混入伪规则。
