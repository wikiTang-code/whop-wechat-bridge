## 本周教训

1. 日度 0DTE 盘前的局部翻正，经常活不过当天收盘后的换月。本周 QQQ 在周三、周四两次 08:00 同列翻正（+5,617,840.22、+4,552,327.84），正垫在收盘滚到下一根日度或月度列后都离开了。要写成「同列清算打印」，不能把过期列的正 Gamma 带到新的一天，更不能据此宣布体制切换。
2. 局部 GEX 变浅不等于风险下降，必须同时看全链。周五盘前 QQQ 局部从 -30,887,596.57 收到 -14,821,404.72，但 chain_neg 从 -306,170,296.23 加深到 -355,193,765.54，远档 630/625/620 加厚。只报局部会说反。
3. 周四收盘滚上周五月度列后，可见阶梯可以几乎没有正档。SPY 只剩 FLOOR 741 / +1,128,362.62，SPX 51 档全负、算法 FLOOR 7085 为负。金额过小或为负的 FLOOR 一律不叫支撑。周五收盘后再滚到下周一薄日度列，负号可以不变，但金额会收缩一个数量级；这不是风险出清，真实周五 OI 要等周一 08:00，且该周一列变成 0DTE 的那一份。
4. 同列符号可以保持深负，但关键行权价已经翻号。NVDA 周五盘前 11-20 仍是 -117.2M，150 却从负墙翻成新 FLOOR，KING 下移到 140。只看列符号会漏掉结构变化。
5. 大跌后的官方列翻号，必须先拆重叠格与窗口滑动。META 周四、NVDA / SOXX / 部分 SPCX 列在周五收盘后，官方数字的「转负」或「加深」有相当一部分是远档正值滑出 ±20 档窗口。AAPL 11-23 才是重叠格主导的翻负，这两种要分开写。pipeline 的「强力翻正 / 转负」在换月、窗口滑动和到期离场时都容易误读，周报和日分析都以同到期、先拆窗口为准。
6. 0DTE 在现货不变时，正负两侧都可以按数量级膨胀（周二盘前 SPY 正侧 +7.4M 到 +75.2M）。这是 gamma / 时间尺度，加上新的清算 OI，不是盘前突然出现等额新仓。
7. `collection.ok=false` 若只缺 SPX，SPY / QQQ 和股票矩阵仍可分析；缺的那一门不要用旧图或旧数字顶上。修复后的第一场只报首印结构，不做假差分。
8. 先看墙背后的金额和到期。本周再次出现零值或近零 FLOOR（周五早场 SPY 699、QQQ 624、SPX 7030 只有 +1,083.34，以及 META 590@12-02、NVDA 146@12-02、SOXL 50@11-27、MU 645@12-02、NBIS 135@12-18）。个股 KING / FLOOR 跨到期迁移，不等于同一张合约在移动。SOXX 则再次证明：现货大跌或中段反弹，都不能把持续为负的月度/周度负柱写成体制翻正。
9. 指数可见阶梯大约只有现价 ±125 点（SPX）。大跌后若外部点位整组都高于上沿，只标明区间外，不要用上沿最近档去对。

## 口径与限制

- 本文只引用仓库 JSON 与已提交的日分析；指数来自 zero_dte，个股来自 matrix。金额单位为美元，表格保留到分；现货和行权价按原值呈现。相对上周五的周跌幅是用收盘现货自行计算的派生值，已在结论中标明。
- 个股「NetGEX（列合计）」为 column_totals 所有到期列之和，属可复算派生值，并非 JSON 中独立的净敞口总字段，也不是全市场敞口。指数主报 local_gex，chain_pos / chain_neg 由可见 ladder 加总，只覆盖窗口内的档，不是全链所有到期。net_gex 是每 1 点变动的 gamma×OI×spot×100，SPX 与 SPY 金额不可横比，个股之间也不可横比。
- KING / FLOOR 沿用快照字段，不自动等同 Put / Call 墙或确定性支撑阻力；个股墙带有到期日，跨到期迁移不等于同一期权仓位移动。
- generated_at 带明确偏移（-05:00），采集时间同时换算为 Asia/Shanghai。文件名时间与该字段可能不同，本文分别列示。
- JSON 来源为 futu-opend，备注称 OI 为 T+1；没有 OCC 处理完成时间或直接 OCC 核验凭据，不据此宣称实时最终结算。盘前快照的现货仍是前收，不含盘前成交价。
- GEX 正负依赖做市商净卖期权等模型假设；快照不证明资金动机或特定对冲交易已发生，不构成价格预测或投资建议。
