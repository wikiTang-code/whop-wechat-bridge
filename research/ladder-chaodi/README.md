# 梯子 + 抄底 指标研究

富途牛牛「梯子」主图通道与「抄底」MACD 背离副图的整理、无未来函数改造，以及在 QQQ / TSLA 上的回测结论归档。

**结论摘要**：做成可复现交易规则后，在 QQQ 日线、QQQ 30 分钟、TSLA 30 分钟上样本外期望 R 均为负。适合继续当看盘辅助，不适合作为自动买卖系统。详见 `reports/梯子抄底体系_验证报告.md`。

## 原版 vs 改进

| | 原版 | 改进/回测版 |
|--|------|-------------|
| 梯子 | `EMA(H/L,26)` 与 `EMA(H/L,89)` 包络 | `EMA(C) ± k×ATR`，中轴更稳 |
| 抄底字样 | `DRAWTEXT`，可长期留在图上 | 强调 `DXDX` **边沿**，交易只用边沿 |
| 成交 | 看盘主观 | 收盘确认，次根开盘 |
| 出场 | 图上「卖出」字（回测未作主规则） | 破短期下轨 B 全清 + 破中轴减半 |
